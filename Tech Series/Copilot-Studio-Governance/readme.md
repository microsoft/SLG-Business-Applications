# Copilot Studio Governance Series

A four-part video series for State & Local Government and Higher Education teams preparing their tenant for governed Microsoft Copilot Studio agent development and usage.

## About this series

Watch the series in order to set up the minimum recommended configuration for Copilot Studio. The sessions cover tenant settings, environment strategy, data loss prevention (DLP) policies, licensing, security roles, billing, and consumption.

## Episodes

### Part 1: Tenant Settings & DLP Policies

Learn how to enable publishing for Copilot Studio agents through tenant settings, protect your tenant with DLP policies, and define an environment strategy.

[Watch Part 1](https://youtu.be/su6vKWZ4I6Y)

### Part 2: Environment Setup and Creation

Learn how to assign environment admins, create an environment, enable generative AI features, and assign a DLP policy exclusion to the new environment.

[Watch Part 2](https://youtu.be/6y4UVMNDxaI)

### Part 3: Licensing and Security Roles

Learn how to provision users to access Copilot Studio and build agents through licensing and security roles.

[Watch Part 3](https://youtu.be/ZKneOZIQW8w)

### Part 4: Billing, Licensing, and Consumption

Learn how to set up a PAYG billing plan, connected to your Azure Subscription, and then assign it to target environments.

[Watch Part 4](https://youtu.be/3Nk3NfktYe4)
